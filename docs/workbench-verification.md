主要覆盖：

- 主 API 参数隔离、独立通道 JSON/SSE、工具去重、截断和超时处理。
- TT 独立预设结构、所选材料/正文/总结完整性、同 outlet 多条内容保留。
- 生成规划、分批审核、直接编辑、单项跳过、只在最终批次推进游标。
- 草案范围更新、非法范围不污染状态、过期审核不能覆盖晚到草案。
- 多调用审核项唯一 ID、创建 UID 回传、后续批读取真实新目标。
- S/P/R 容器的单条文风检查、编号冲突、局部 closed 删除及最终记录。
- 同一 key 在 carry 和各批次之间累积已保存的归档去向。
- v1→v2 保留原笔记、任务/快照薄索引、默认30天有界清理、Markdown 导出。
- 多目标/多段补丁、同书合并写入、并行无关修改保留及目标冲突。
- 写前快照失败不写宿主；写后回执失败不报告完成；原批次幂等恢复。
- 跳过已有意图先恢复事实，撤销未落盘脏缓存；不确定结果不盲目重放。
- Char 已落盘回执丢失后的内存同步，保护请求期间表单的新编辑。
- 停止后旧工具调用不能进入重试批次，fallback AbortSignal 监听及时清理。

## 性能核查

- 工作台与宿主适配器懒加载，正文事件不扫描世界书或全量历史。
- 提醒按事件合并与阈值去重，按聊天缓存小型提醒设置。
- 流式文本80ms合并更新，保持消息节点；输入差异180ms合并，草案900ms防抖，输入法组合期间暂停重算。
- 正文差异用独立 Worker 和有界算法；Worker 不可用时，长文降为整段差异。
- 材料50项、任务30项、快照40项分段加载。列表只读小型索引；完整版本按需读取。
- 导出按记录让出事件循环并限制总量；到期清理一次最多100个快照。
- 导入世界书的原始 UID 每本书只建一次 Map，消除材料读取中的逐条数组全表查找。
- 没有用“测试很快”推断手机不卡顿。真实 TT 和手机的响应时延尚未测量。

## 接口与未验证边界

后台与正文互扰的结论来自精确版本的 [agent.js](https://github.com/Darkatse/TauriTavern/blob/fff9af0333be97697be2313981699ab0ce35c236/src/tauri/main/api/agent.js)、[提交桥](https://github.com/Darkatse/TauriTavern/blob/fff9af0333be97697be2313981699ab0ce35c236/src/tauri/main/api/agent-chat-commit-bridge.js)和[展示收尾](https://github.com/Darkatse/TauriTavern/blob/fff9af0333be97697be2313981699ab0ce35c236/src/tauri/main/api/agent-chat-presentation-checkpoint.js)：当前后台配置不订阅前台展示、不授权正文提交，收尾不调用正文按钮或全局停止。取消回执仅代表请求已受理，未冒充底层任务终态。

尚未验证实际 TT 中的付费请求、提供商工具调用兼容、手机下滑手势与像素布局。尝试运行合成页面截图时，当前执行环境拒绝 Chromium 所需的 socket；没有获得截图，不把 DOM 测试称为视觉验收。

独立 API 首版支持 OpenAI Chat Completions 兼容格式。主 API 不导入 TT 的任意额外请求 body 覆盖项，依赖这些字段的代理仍有兼容限制。

使用 TT 已保存预设时保留其结构、角色、深度和宏处理，但不会复现全部第三方扩展的正文生成事件。所需材料被预设关闭或预算截断时拒绝运行。

记忆侧仅只读历史总结。普通正文隐藏标记不影响原文读取；如果 TT 只加载了末尾窗口，当前记忆接口的本地索引不能证明绝对楼层衔接，归档会提示加载完整历史或从0楼提供原文。L0 专项提取与其他记忆数据调用未实现。

## 数据影响与回退

复用 `mnemosyne-notes-v1` 数据库，schema 升至2；保留原 `meta/items`，增加任务与快照索引，完整工作台正文仍存于同库 `meta` 命名空间。不创建记忆数据库。

每个通过审核的写入先持久化新旧版本及保存意图。没有跨世界书、角色卡和 Persona 的全局原子事务；部分成功按实际结果恢复，未确定结果不推进归档游标。

用户内容回退由“旧快照 → 用旧版本创建回退草案”完成，重新展示当前版本与旧版本的差异，确认后生成新的修改快照。不会直接覆盖随后出现的不同版本。原 rolling 消息没有写入或删除接口。

自动清理仅处理超出设置期限的终态快照；prepared/unknown 意图保留。快照到期后不能依赖本机快照回退，可在到期前多选导出 Markdown。

插件代码若需回退，应保留数据库版本2的兼容读取；直接安装只按版本1打开数据库的旧插件会触发 IndexedDB 版本错误。不能通过删除数据库来解决版本问题。已有笔记没有被迁移出原对象存储。
