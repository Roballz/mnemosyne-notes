# Mnemosyne记事簿

TauriTavern 独立前端扩展。楼层收藏、手机消息和备忘录均从当前聊天原文回看，聊天切换与分支各有自己的记事簿。

## 安装与共存

在 TauriTavern 的「扩展 → 安装扩展」中粘贴下面的 Git URL，分支栏留空。

```text
https://github.com/Roballz/mnemosyne-notes.git
```

安装完成后重载前端。记事簿和日用记忆分别安装到独立目录，可以同时使用。今后可在扩展管理中为记事簿单独点「更新」。本插件也已启用 `auto_update`，自动更新的触发时机由宿主设置决定。

## 使用

- 点贴边书签，收藏聊天可视区中央的楼层。点正文右上的书签可以精确选择。弹窗内一次选好备注、多个人物、多个合集和关键词。再次收藏同一楼进入编辑。
- 从书签往屏幕内侧滑动，打开主面板。主面板向停靠侧滑动即可收回。长按拖动书签后松开，可上下移动或吸附到另一侧。「扩展设置」也有打开入口。
- 「收藏」支持人物与合集两个方向的分组，以及人物、合集、关键词组合筛选。「消息」可按合集或人物浏览，再按剧情日期回看。
- 「收藏 / 消息 → 目录管理」可搜索完整路径，展开目录，点名称编辑，点「＋」创建子目录。人物、合集均支持三级；在编辑页选择上级目录即可移动，进入目录后也可从右上角编辑。各级都可设置元素、名称属性、多个完整名称和可选正则。完整名称和正则任一匹配即可。正则第一个捕获组或命名组 `person` 可提取人物。一个块可以同时属于多个合集。规则中的人物标签可用半角或全角逗号、分号以及「、」分隔，如「玦；崔冬」。同名人物填完整路径。
- 在合集编辑页底部点「删除合集」并确认。子目录上移一级，遇到同名会添加序号。楼层收藏及备注保留；同一消息在其他合集的归属保留，仅命中已删合集的消息转入「未分类」。
- 默认发现 `div[data-nvwa-ui]`。陌生名称的通知可直接选择合集并记住别名，也可到「消息 → 按合集 → 未分类」稍后处理。详情中的「过滤此名称（黑名单）」需二次确认；同名旧消息随即隐藏，新消息也会跳过。可从过滤设置移除此名称并恢复识别。快捷回复按钮、脚本和远程资源均不会在阅读器中运行。
- 「设置 → 过滤标签与剧情日期」可按属性名或 UI 名称忽略整个块，可设置剧情时间的标签或捕获正则。「零命中」默认关闭，开启后只在有实际 div 且缺少可识别标记时提醒。历史回填静默处理。
- 在「设置 → 导航栏位置」可将收藏、消息、设置切换到底部。选择窗口使用记事簿的主题色。
- 在设置中切换白绿、深蓝和墨绿霓虹主题，外部气泡可单独切换液态玻璃、磨砂光感玻璃，选择预设或自定义色值，换用书签、表情或本地图片图标。设置中的两个像素滑条可分别调节悬浮头和通知单行高度，拖动时实时预览。「气泡透明度」可在 0%–90% 之间调节，值越大，收藏头和通知下方的正文越清晰。通知默认从收藏头内侧上方弹出，也可移到应用顶部。

## 本地数据与性能

收藏、手写备注、关键词、规则和来源索引写入当前 WebView 的专用 IndexedDB。消息原文、HTML、图片与草稿按钮均不写入索引。打开详情时从聊天读取，并校验来源。移除原文后，收藏备注仍保留。数据目录迁移或清理 WebView 前，可在设置里导出各聊天的收藏与规则，回到相同聊天后导入；自动索引由原文重建。

首次打开记事簿按每批最多 16 楼整理旧聊天，中途退出后可续扫。新回复、编辑和 swipe 只处理对应楼层；流式文字不触发连续识别。识别和自定义正则在专用 Worker 中运行。后续打开只加载目录页与必要的来源校验。同一标记新增别名时只重新处理已有候选楼层。新增外层属性、修改过滤或日期规则时会重新分批扫描。停用插件期间修改过旧楼层，可用「重新扫描当前聊天」校准索引。

## 开发验证

扩展直接使用 ES 模块，安装时无需构建或安装依赖。开发测试使用 Node.js 22 或更高版本，在此目录执行 `npm install` 和 `npm test`。测试数据均为合成样例。
